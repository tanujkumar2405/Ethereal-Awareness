# EtherealAwareness

A premium static website for EtherealAwareness.com.

## Overview

This project delivers a polished, mobile-first, static website for Ethereal Awareness, a professional platform specializing in paranormal education, investigator training, psychic development, tarot reading, and spiritual guidance.

## Structure

- `index.html` — Homepage showcasing programs, testimonials, mission and conversion-driven CTAs.
- `about.html` — Story of the Ethereal Awareness core team, research principles, mission, and ethics.
- `courses.html` — Course catalog with filtering, search, and WhatsApp registration.
- `workshops.html` — Workshop listings with countdown timers and urgency messaging.
- `sessions.html` — One-on-one private sessions and guided bookings.
- `contact.html` — Contact form, mailto support, social links, and map placeholder.
- `faq.html` — Animated FAQ accordion with course, workshop and session guidance.

- `css/style.css` — Core theme and layout styles.
- `css/responsive.css` — Responsive breakpoints and mobile refinements.
- `css/animations.css` — Motion, reveal effects, and animation utilities.
- `js/main.js` — Navigation, interaction, filters, testimonials, countdowns.
- `js/animations.js` — Page animations and motion enhancements.
- `js/forms.js` — Form validation and submission feedback.
- `js/seo.js` — Canonical and schema utilities.
- `sitemap.xml` — Search engine sitemap with site structure.
- `robots.txt` — Robots policy allowing full site crawling.

## Usage

Open `index.html` in the browser to view the site.

## Notes

- Designed for high performance with lightweight vanilla HTML, CSS, and JS.
- SEO-ready metadata, Open Graph, Twitter cards, and structured schema.
- Accessible navigation, keyboard-friendly focus states, and reduced-motion support.
